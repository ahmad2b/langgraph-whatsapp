# Security policy

## Reporting a vulnerability

If you find a security issue, such as a way to message the agent without being allowed, read another person's conversation, or reach the local services from outside your machine, please report it privately:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.

Only the maintainer can see the report. Please don't open a public issue for it, so the fix can ship before the details are public. If you can't use GitHub's form, email ahmadshaukat_4@outlook.com instead.

I'll reply within a few days and keep you updated until it's fixed.

Bugs, questions and ideas that aren't security issues are welcome in [issues](https://github.com/ahmad2b/langgraph-whatsapp/issues).

## Supported versions

Fixes go to the latest `main` branch.
